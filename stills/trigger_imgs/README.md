# 上传影集

1. [选择本组照片](https://github.com/fivsevn/fivsevn-roll/upload/main/stills/trigger_imgs)，保留原文件名。
2. 提交到 `main`，一次推送发布一组。
3. 等待 [Actions](https://github.com/fivsevn/fivsevn-roll/actions/workflows/build.yml) 成功，查看 [Stills](https://roll.fivsevn.com/stills/)。

支持 JPG/JPEG、PNG、WebP、GIF。手机上传前先拉取最新 `main`；线上核验成功后自动清理入口原图。
